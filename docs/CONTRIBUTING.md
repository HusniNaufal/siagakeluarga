# Aturan Kontribusi

1. Jangan push langsung ke `main`. Kerja di branch `feat/nama-fitur`, `fix/nama-bug`, atau `docs/nama`.
2. Merge lewat Pull Request, PM yang review.
3. Jangan `git push --force` dan jangan hapus/ubah riwayat commit (dinilai juri).
4. Commit kecil dan sering. Format pesan: `feat: tambah endpoint risk`, `fix: ...`, `docs: ...`, `chore: ...`.
5. Jangan commit `.env`, API key, atau password. Gunakan `.env.example`.
6. Kontrak API ada di `docs/api-contract.md`. Perubahan kontrak harus lewat PM.
7. Pakai AI tool apa pun? Catat di tabel penggunaan AI pada README.
